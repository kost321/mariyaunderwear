# Mariya Underwear

Online store for women's nightwear and homewear: Next.js 15 + Payload CMS 3, Tailwind 3.

- Before any storefront UI change, read `DESIGN.md` (colors, fonts, shapes, motion, copy, decisions
  that override Figma and generic guidelines).
- Admin-facing changes: update `docs/admin-guide.md` (shown as «Довідка» at `/admin/help`).
- UI checks: `/audit` (browser + axe), skills `web-design-guidelines` (code review) and
  `emil-design-eng` (interaction/animation polish). Project rules in `DESIGN.md` take precedence over
  both skills.
